## 1. 里程碑目标

搭起"可启动、可注册、可路由、可建库、可构建"的完整工程骨架，为 M1 开始的业务开发提供地基。本里程碑不含任何业务功能，但要求**全部基础设施链路真实跑通**，不允许"先空着后补"。

## 4. 本地开发环境完整启动指南（从零开始）

### 4.1 一次性准备

```bash
# 1) 中间件（Homebrew；已装可跳过）
brew install postgresql@18 redis rabbitmq
brew services start postgresql@18 redis rabbitmq

# 2) Nacos（单机模式；注意其脚本要写自身 logs 目录）
sh ~/Downloads/nacos/bin/startup.sh -m standalone
# 验证：curl http://127.0.0.1:8848/nacos/ 返回 200；控制台 http://localhost:8080（nacos/nacos）

# 3) 创建四个项目库（仅需一次；pg_trgm 仅 task_db 需要）
PGPASSWORD=root psql -h 127.0.0.1 -U postgres -d postgres \
  -c 'CREATE DATABASE auth_user_db' -c 'CREATE DATABASE task_db' \
  -c 'CREATE DATABASE notification_db' -c 'CREATE DATABASE stats_db'
PGPASSWORD=root psql -h 127.0.0.1 -U postgres -d task_db -c 'CREATE EXTENSION IF NOT EXISTS pg_trgm'
# 表结构无需手工执行：服务首启时 Flyway 自动迁移
```

### 4.2 后端启动

```bash
cd /Users/minghui.liu/CodeSpace/TaskFlow

# 首次必须：把父 POM 与 common 装进工作区本地仓库
# （本机 Maven 默认仓库在 ~/Downloads 下受沙箱限制不可用，必须指定 -Dmaven.repo.local）
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
export MVN_REPO=/Users/minghui.liu/CodeSpace/TaskFlow/.m2/repository
mvn install -N -Dmaven.repo.local=$MVN_REPO
mvn install -pl common -DskipTests -Dmaven.repo.local=$MVN_REPO

# 日常启动（每个模块一个终端，或用 nohup 后台）：
mvn spring-boot:run -pl gateway-service      -Dmaven.repo.local=$MVN_REPO
mvn spring-boot:run -pl auth-user-service    -Dmaven.repo.local=$MVN_REPO
mvn spring-boot:run -pl task-service         -Dmaven.repo.local=$MVN_REPO
mvn spring-boot:run -pl notification-service -Dmaven.repo.local=$MVN_REPO
mvn spring-boot:run -pl stats-service        -Dmaven.repo.local=$MVN_REPO
```

启动顺序无强依赖；网关在业务服务之后启动可立即发现，先启动也会等注册后自动可用。

### 5.3 排障速查（本里程碑实际踩过的坑）

| 症状 | 原因 | 解法 |
|---|---|---|
| 网关 8080 一直 302 到别的页面 | Nacos 3.x 控制台占 8080 | 网关改 8000；前端代理同步改 |
| mvn 报 `.part.lock No such file` | 默认本地仓库在 ~/Downloads，沙箱禁写 | 一律加 `-Dmaven.repo.local=<仓库根>/.m2/repository` |
| `mvn spring-boot:run -pl x` 找不到 common | 单模块运行不走 reactor | 先 `mvn install -N` + `install -pl common` |
| 服务启动报 `No spring.config.import` | SCA 2023 的 nacos-config 需要显式 import | M0 暂移除 nacos-config 依赖（M1 需要时再配 `spring.config.import`） |
| `pnpm add` 报 Unexpected store location | 全局 store 位置不一致 | 加 `--store-dir /Users/minghui.liu/CodeSpace/TaskFlow/.cache/store` |
| vue-tsc 报 Unknown compiler option | @vue/tsconfig 0.9 需要 TS ≥ 5.7 | 升级 typescript 到 ^5.8 |
| `java -version` 显示 1.8 | 系统默认 JDK 是 8 | 所有 mvn 命令前置 `JAVA_HOME=/opt/homebrew/opt/openjdk@17` |
| brew services 启动 rabbitmq 报权限错 | 沙箱禁写 ~/Library/LaunchAgents | 已由用户在本机直接配置启动 |

## 6. 已知限制（留给后续里程碑）

3. Flyway 目前只有正向迁移；回滚靠重建库（开发期可接受）。
4. 登录页按钮仅占位，M1 对接 `POST /auth/api/v1/login`。
5. 定时任务、MQ 拓扑、邮件均为依赖就位但未启用（M3/M5）。

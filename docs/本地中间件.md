## 项目端口分配（M0 实测确认）

| 端口 | 占用 |
|---|---|
| 8000 | gateway-service（**注意：8080 被 Nacos 3.x 控制台占用，网关用 8000**） |
| 8080 | Nacos 控制台 |
| 8848 / 9848 | Nacos 服务注册（HTTP / gRPC） |
| 8081-8084 | auth-user / task / notification / stats 四个业务服务 |
| 5432 / 6379 / 5672 | PostgreSQL / Redis / RabbitMQ |

## 项目数据库（已创建）

`auth_user_db`、`task_db`、`notification_db`、`stats_db`（owner: postgres；task_db 已启用 pg_trgm 扩展）。四个服务的 Flyway 迁移已在首次启动时自动执行：共 19 张表 + 种子数据（3 角色、42 行权限矩阵、初始 admin，开发密码 Admin@123，首次登录强制改密）。

## 开发环境启动顺序

1. 确认中间件运行：`brew services list`（postgresql@18 / redis / rabbitmq）+ Nacos（`sh ~/Downloads/nacos/bin/startup.sh -m standalone`）
2. 启动后端：`JAVA_HOME=/opt/homebrew/opt/openjdk@17 mvn spring-boot:run -pl <模块> -Dmaven.repo.local=<仓库根>/.m2/repository`（首次需先 `mvn install -N` + `mvn install -pl common`，让 common 进入本地仓库）
3. 前端：`cd frontend && pnpm dev`（代理已指向网关 8000）

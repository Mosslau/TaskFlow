# TaskFlow 任务管理系统 UI 设计规范

> 版本：v1.0 · 状态：待评审
> 关联 PRD：[`docs/PRD-任务管理系统-v1.0.md`](PRD-任务管理系统-v1.0.md)（功能与交互需求以此为准）
> 关联原型：[`docs/ui/`](ui/)（关键页高保真原型，按本规范实现）；旧版需求推演原型 `docs/任务管理系统原型.html` 保留作需求参考，不再作为视觉基准
> 设计规范：frontend-design 技能

---

## 1. 设计原则

1. **状态即颜色** —— 五种任务状态对应五种专属色（2.2），贯穿列表色点、日历标记、统计图表、KPI。用户扫一眼颜色即知任务阶段，这是 TaskFlow 的视觉识别核心。
2. **表格为家** —— 信息密度优先，装饰让位；行内快捷操作悬停显现，保持行面干净。
3. **一处亮色** —— 品牌主色青碧只给主行动（主按钮、链接、选中态）与"进行中"状态，页面不出现第二处彩色装饰。
4. **空态与报错给方向** —— 空列表告诉用户下一步做什么；报错说清原因与缺少的权限（落实 PRD 3.5.2"拒绝原因提示"）。

## 2. 色彩系统

### 2.1 品牌与结构色

| 角色 | 色值 | 用途 |
|---|---|---|
| 青碧（主色） | `#0E7C86` | 主按钮、链接、选中导航、聚焦描边；"进行中"状态色 |
| 青碧-深 | `#0A5F67` | 主按钮 hover |
| 青碧-浅底 | `#E3F2F3` | 选中行底、标签底色、聚焦光晕 |
| 墨青 | `#12242E` | 侧边栏、抽屉标题栏、主标题 |
| 纸灰 | `#F6F7F9` | 内容区底色 |
| 纯白 | `#FFFFFF` | 卡片、表格、弹窗容器 |

### 2.2 任务状态色（产品识别核心）

| 状态 | 色值 | 色点 | 语义 |
|---|---|---|---|
| 待办 new | `#8A97A8` | ● | 中性灰蓝，"还没开始" |
| 进行中 doing | `#0E7C86` | ● | 同品牌主色，"正在流动" |
| 待验收 wait | `#D9822B` | ● | 琥珀，"等你确认" |
| 已完成 done | `#2F9E6E` | ● | 松绿，"搞定" |
| 已归档 close | `#C3CBD4` | ● | 浅灰，"封存" |

规则：状态出现处必须先色点后文字（`● 进行中`），色点直径 8px；统计图表系列色与状态色一一对应，禁止另起配色。

### 2.3 功能色

| 角色 | 色值 | 用途 |
|---|---|---|
| 成功 | `#2F9E6E` | 操作成功反馈（同"已完成"） |
| 预警 | `#D9822B` | 临期提醒、二次确认图标 |
| 危险 | `#C8493F` | 删除、驳回；P0 优先级；逾期标记 |
| 信息 | `#5E6D82` | 次要提示 |

### 2.4 中性色阶

| 色值 | 用途 |
|---|---|
| `#1F2D3D` | 主文案 |
| `#5E6D82` | 次要文案 |
| `#8A97A8` | 辅助文案、占位符 |
| `#D8DEE6` | 边框、分割线 |
| `#E8ECF1` | 表格表头底、悬停行底 |
| `#F6F7F9` | 页面底色 |

### 2.5 优先级标识

优先级不靠颜色全家桶，用**文字 + 克制色标**：P0 砖红加粗、P1 琥珀、P2 主文案色、P3 辅助灰。逾期任务的到期时间一律砖红 `#C8493F`（PRD 4.2.2）。

## 3. 字体与排版

| 项 | 规范 |
|---|---|
| 字体族 | `-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", sans-serif`，不引入 Web 字体 |
| 字阶 | 12px 辅助 / 13px 表格次要 / 14px 正文基准 / 16px 卡片标题 / 20px 页面标题 / 24px 抽屉标题 / 28px KPI 大数字 |
| 字重 | 400 常规 / 500 强调 / 600 标题与 KPI 数字 |
| 行高 | 正文 1.6；表格行 1.4；标题 1.3 |
| 数字 | 任务编号、时间、KPI 一律 `font-variant-numeric: tabular-nums`，逐位对齐 |
| 行长 | 描述性文本 ≤ 80 字符；表格单元格超出省略号 + 悬停全文 |

## 4. 间距与布局栅格

### 4.1 间距刻度（4px 基网）

`4 / 8 / 12 / 16 / 24 / 32 / 48`。组件内部 8–12，卡片内边距 16–24，区块间隔 24，页面级留白 32。

### 4.2 页面骨架

```
┌──────────┬────────────────────────────────────────┐
│          │ 顶栏 56px：面包屑 · 全局搜索 · 铃铛 · 头像 │
│  侧边栏   ├────────────────────────────────────────┤
│  墨青     │  内容区（纸灰底，24px 内边距）           │
│  232px   │  ┌─白色容器：圆角 8px、1px #D8DEE6 边框─┐ │
│  品牌区   │  │ 无投影装饰；层级靠底色与边框区分      │ │
│  导航     │  └──────────────────────────────────┘ │
│  底部用户卡│                                        │
└──────────┴────────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 侧边栏 | 宽 232px，墨青 `#12242E`；导航项高 44px，选中项左侧 3px 青碧条 + 青碧浅底 15% 透明；导航角标（待办+进行中数）用砖红圆点数字（PRD 4.2.2） |
| 顶栏 | 高 56px，白底，下边框 1px；铃铛未读角标砖红 |
| 内容区 | 最小支持宽度 1280px（PRD 7.4），窄于此提示使用桌面浏览器；表格流式铺满 |
| 详情抽屉 | 右侧滑出，宽 720px，墨青标题栏 48px，遮罩 `rgba(18,36,46,.45)` |

## 5. 组件规范

### 5.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | 青碧底白字，hover 青碧-深，圆角 6px，高 32px | 页面唯一主行动（新建任务、保存） |
| 次按钮 | 白底 1px 边框，主文案色 | 常规操作 |
| 文字按钮 | 青碧文字无底色 | 行内操作、次要入口 |
| 危险按钮 | 砖红文字 / 砖红底（二次确认后） | 删除、驳回 |
| 禁用 | 灰底 `#E8ECF1` + 辅助灰文字 | 无权限时**禁用并附提示**（PRD 3.5.1） |

### 5.2 表格

- 行高 48px，表头 13px 次要文案 + `#E8ECF1` 底；行分隔 1px `#D8DEE6`；悬停行 `#F6F7F9`。
- 编号列 tabular-nums；状态列"色点 + 文字"；到期时间逾期砖红；操作列文字按钮悬停显现。
- 分页右下：每页 10 / 20 / 50（PRD 4.2.2）。

### 5.3 筛选栏

白色容器顶部单行排布：关键字搜索框（240px）+ 各下拉筛选项 + 范围快捷切换（全部/我创建的/指派给我的/已逾期，分段控件）。选中条件以标签形式回显，可单个清除。

### 5.4 详情抽屉（720px）

自上而下：墨青标题栏（编号 + 标题 + 状态色点）→ 操作按钮行（按权限与状态启用）→ 字段区（双列栅格）→ 进度条（青碧，tabular-nums 百分比）→ 子任务清单 → 评论区（正序）→ 附件区 → 操作时间线（倒序，竖线 + 色点）→ 关联邮件记录。

### 5.5 反馈与异常

| 场景 | 规范 |
|---|---|
| 成功 | 顶部轻提示，松绿，2 秒自动消失；文案与按钮同词（"保存"→"已保存"） |
| 报错 | 表单内联红字 + 顶部错误提示；越权报错写明"需要 XX 权限，当前角色 XX"（PRD 3.5.2） |
| 二次确认 | 删除/驳回用居中弹窗：预警色图标 + 后果说明 + 危险主按钮 |
| 空态 | 居中插画位（120px 灰色图形）+ 一句说明 + 一个行动按钮（如"新建第一个任务"） |
| 加载 | 表格/卡片用骨架屏（灰条呼吸），不用全屏 spinner |

### 5.6 动效

- 过渡统一 150–200ms `ease-out`；抽屉滑入 240ms；悬停变色 120ms。
- 非用户触发的动效只允许骨架屏呼吸；尊重 `prefers-reduced-motion`。

## 7. 文案规范

1. 按钮说人话、动词开头："新建任务"、"提交验收"，不用"确定/提交"。
2. 动作全程同名：按钮"提交验收" → 提示"已提交验收"。
3. 报错不道歉、不含糊："该任务存在 2 个未完成子任务，暂不能提交验收"，不说"操作失败"。
4. 空态给方向："还没有指派给你的任务，刷新看看或联系任务管理员。"
5. 术语以 PRD 1.2 为准：处理人（非负责人）、待验收（非待审核）。

## 8. Element Plus 主题落地

Vue3 工程通过 CSS 变量覆盖实现本规范（`frontend/src/styles/theme.scss`）：

```scss
:root {
  --el-color-primary: #0E7C86;
  --el-color-primary-light-3: #4AA3AB;
  --el-color-primary-light-5: #87C2C8;
  --el-color-primary-light-7: #BADDE0;
  --el-color-primary-light-8: #CFE8EA;
  --el-color-primary-light-9: #E3F2F3;
  --el-color-primary-dark-2: #0A5F67;
  --el-color-success: #2F9E6E;
  --el-color-warning: #D9822B;
  --el-color-danger: #C8493F;
  --el-color-error: #C8493F;
  --el-text-color-primary: #1F2D3D;
  --el-text-color-regular: #5E6D82;
  --el-text-color-secondary: #8A97A8;
  --el-border-color: #D8DEE6;
  --el-border-color-light: #E8ECF1;
  --el-fill-color-light: #F6F7F9;
  --el-border-radius-base: 6px;
  --el-font-size-base: 14px;
}
/* 全局补充 */
.tf-num { font-variant-numeric: tabular-nums; }        /* 编号/时间/KPI 数字 */
```

状态色点、优先级标识、侧边栏（墨青）不属于 Element 默认主题范围，由业务组件按 2.2 / 2.5 实现。

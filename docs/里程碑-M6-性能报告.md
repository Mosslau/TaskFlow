# TaskFlow 里程碑报告 · M6.2 性能验证（轻量）

> 依据：[实施计划 v1.0](实施计划-v1.0.md) 第 8 章 6.2 | 目标口径：[PRD 7.1](PRD-任务管理系统-v1.0.md)
> 验证日期：2026-09-09 | 验证人：M6 联调验证（性能专项）

## 1. 结论摘要

全部接口在 **10,000+ 行真实库表规模**下实测，PRD 7.1 的 **5 项性能指标全部达标**（余量 100~1000 倍）：

| 指标（PRD 7.1） | 目标 | 实测（3 轮取中位） | 结论 |
|---|---|---|---|
| 列表接口 P95 | ≤ 1 s | **6.1 ms**（page=1） | ✅ 达标 |
| 详情接口 P95 | ≤ 1 s | **2.7 ms** | ✅ 达标 |
| 统计总览接口 P95 | ≤ 2 s | **7.5 ms**（range=all） | ✅ 达标 |
| CSV 导出 | 10000 行内同步返回 | **0.21 s / 10000 行**（1.35 MB） | ✅ 达标 |
| Excel 导入 | 500 行 ≤ 30 s | **0.67 s**（中位；最坏 1.24 s） | ✅ 达标 |

次要观测：并发 10 下列表 P95 = 19.8 ms（P99 = 25.6 ms），无劣化迹象；stats 全量回填 10508 条任务仅 0.55 s。

## 3. 方法学

- **工具**：`curl -w %{time_total}` + Python `requests.Session`（keep-alive 连接复用，串行采样）+ `xargs -P 10`（并发参考）+ awk/Python 分位数。
- **流程**：每个接口预热 N 次（JIT/连接池热身）→ 连测 **3 轮**，每轮 60~120 个样本 → 每轮统计 P50/P95/P99/max/avg → **最终取 3 轮各分位数的中位数**（达标判据）。
- **样本口径**：仅统计业务成功样本（HTTP 200 且 `code=0`）；失败样本单独计数（本次全程 0 失败）。
- **详情采样池**：跨库取 118 个真实任务 id（含带时间线的种子任务、导入任务与演示任务）轮询采样，贴近真实混合负载。
- **导出/导入**：大操作单请求计时，3 轮取中位数；导出校验返回行数（wc -l）与字节数。
- **统计口径**：`/stats/api/v1/overview?range=all` 与 `range=month` 分别采样（预聚合表查询）。

## 5. 与目标对比结论

1. **列表/详情 P95 ≤ 1 s**：实测 6.1 / 2.7 ms，达标（余量 > 150×）。列表单页含可见性过滤 + COUNT(*) + 子任务数聚合 + Redis 用户快照姓名解析；10k 行下 COUNT 与分页均在索引路径内。
2. **统计 P95 ≤ 2 s**：实测 7.5 ms，达标（余量 > 250×）。得益于 M5 预聚合（stats_task_daily/stats_assignee_load 事件驱动维护，查询无实时全表扫描），符合 PRD "禁止实时全表扫描" 设计。
3. **导出 10000 行 ≤ 30 s**：实测 0.21 s，达标（余量 > 140×）。10,000 行单次查询 + 内存拼 CSV，1.35 MB 响应。
4. **导入 500 行 ≤ 30 s**：实测中位 0.67 s / 最坏 1.24 s，达标（余量 > 24×）。500 行单事务逐行创建（含时间线 + 事件 outbox + 通知链路）。
5. **数据规模受限说明**：原库任务量 7 行（<200），已按计划灌满至 10k+ 实测；"导出 1 万行"在受控筛选（=10,000 行）下实测，无需外推。

## 6. 瓶颈与建议（后续关注点，当前均非瓶颈）

| # | 观察 | 建议 |
|---|---|---|
| 1 | 导出 1.35 MB / 0.21 s；超过 10000 行设计上走 `2010` 拒绝而非异步任务 | PRD 7.1 预留"超时转异步 + 站内通知下载"，当前未实现异步通道；如业务需要超大导出，按 PRD 补充异步导出（一期阈值内同步即可） |
| 2 | 列表每次请求含 COUNT(*) + 本页子任务数两条聚合查询 | 数据量 < 百万级无感知；超大规模（>50 万任务）再考虑按范围缓存 total |
| 3 | 详情/列表每请求读 Redis `auth:user:snapshot` 全量 JSON 反序列化（~KB 级） | 当前开销 <1 ms；若用户数上千再评估按需取名或本地缓存 |
| 4 | 并发 10 下 P95 升到 ~20 ms（连接/线程开销） | 本机压测属正常；生产网关前加 Nginx 连接池/gzip 即可 |
| 5 | 统计 range 依赖预聚合表 | 保持事件幂等（processed_event）+ 每日对账/rebuild 兜底（M5 已建） |

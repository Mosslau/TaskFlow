### 代码结构

```
task-service/src/main/java/com/taskflow/task/
├── client/      UserClient（Feign 调 auth-user，身份头透传）
├── config/      AuthContext / AuthInterceptor（读共享 Redis 权限缓存）/ RequirePerm /
│                WebConfig / GlobalExceptionHandler / MybatisPlusConfig /
│                FeignConfig（身份头透传）/ RabbitConfig（topic exchange + 调度开关）/
│                StringJsonbTypeHandler
├── entity/      Task / TaskTimeline / EventOutbox
├── mapper/      TaskMapper（含 nextTaskNo 序列取值）/ TaskTimelineMapper / EventOutboxMapper
├── service/     TaskService（CRUD + 状态机 + 可见性 + 时间线 + outbox 写入）

└── controller/  TaskController（接口 #19-32）

frontend：api/task.ts、views/task/TaskListView.vue、components/TaskDetailDrawer.vue、
          TaskActionDialogs.vue、composables/useTaskUserOptions.ts
```

## 4. 踩坑与修复记录

| 问题 | 原因 | 修复 |
|---|---|---|
| eventId UUID 无 TypeHandler | MyBatis 3.5.16 没有内置 UUID 处理器 | eventId 改 String 映射（写入靠 DB 默认值；读取 getString 正常） |
| 投递后回写 delivered 报类型错 | String 形式的 event_id 出现在 UPDATE SET 里写 UUID 列 | `@TableField(updateStrategy = NEVER)` 不回写不可变列 |
| Feign 报 No Feign Client for loadBalancing | 按服务名调用缺 loadbalancer | task-service 补 spring-cloud-starter-loadbalancer |
| M1 的 5000 与测试残留 | `-parameters` 编译参数在增量编译下被跳过 | 协议：改 pom/编译配置后必须 `clean` 重建（已记录 M0 排障表） |
| 测试脚本中文 query 未编码 | curl URL 直放中文 | 测试侧用 `-G --data-urlencode`（应用无问题） |

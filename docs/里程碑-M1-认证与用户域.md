## 3. 验收实测记录（全部通过）

| 验收标准 | 实测结果 |
|---|---|
| admin 登录返回令牌与权限点 | ✅ token + refreshToken + 14 权限点 + mustChangePassword |
| 连续 5 次失败锁定 15 分钟 | ✅ 第 1-4 次 3002（remainingAttempts 4→1），第 5 次起 3003；不存在账号同样计数（防爆破） |
| 改密后旧令牌立即失效 | ✅ 改密 code=0 → 旧 token 访问 3005；新密码可登录 |
| 矩阵修改下一请求生效 + 审计 | ✅ user.create 开启即时生效；审计日志含操作人姓名与变更前后值 `{"create":{"user":[false,true]}}` |
| admin 的 manageUser/setPerm 不可关闭 | ✅ 返回 3009 |
| 权限点服务端独立鉴权 | ✅ user 角色访问用户管理 3001（details 指明缺 manageUser）；部门列表登录即可查 |
| 越权通道 | ✅ 无令牌 401；绕过网关直连 8081 因无身份头同样被拦（3005） |
| 账号唯一 | ✅ 重复账号 3007 |

## 4. 踩坑与修复记录

| 问题 | 原因 | 修复 |
|---|---|---|
| 审计日志写入 500 | PG jsonb 列不接受 setString | 新增 `StringJsonbTypeHandler`（`setObject(Types.OTHER)`）+ 实体 `@TableField(typeHandler=)` + `@TableName(autoResultMap=true)` |
| `@RequestParam` 参数名丢失 500 | 编译未保留参数名 | 父 POM compiler 插件加 `<parameters>true</parameters>` |
| 锁定逻辑对不存在账号不生效 | 失败计数只在密码校验失败分支 | 账号不存在也计数；第 5 次直接返回 3003 |
| 测试改密后登录失败 | 测试把 admin 密码改了没改回 | 测试脚本末尾改回 Admin@123（开发密码） |

## 5. 已知限制

1. 直连业务服务端口（8081-8084）只校验身份头存在性、未验签——内网信任模型，生产应由网络层限制仅网关可达（M6 部署核查项）。
2. 用户快照缓存（任务展示姓名用）将在 M2 任务服务接入时补。
3. API Key 的网关鉴权链路（X-API-Key 回源校验）在 M3 实现，本期仅完成管理接口。
4. 前端权限矩阵/审计日志标签页未做标签级权限隐藏（页面级已被 manageUser 保护）。
5. ~~nacos-config 未接入（M0 遗留）~~ → **M1 复盘正式决定不接**（2026-09-06）：运行时配置用 application.yml + 环境变量已够用，配置中心只增加运维面；确有多环境集中配置需求时再启用（加回依赖并配置 `spring.config.import: optional:nacos:`）。此遗留项关闭。

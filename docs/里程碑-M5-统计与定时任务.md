## 4. 踩坑与修复记录

| 问题 | 处理 |
|---|---|
| task.assigned 事件载荷缺 priority,stats 无法按优先级分桶 | task-service writeOutbox 载荷补 priority(字段只增不改) |
| Feign 在 MQ 消费线程无请求上下文 | FeignConfig 非请求线程注入系统身份头(X-User-Id:0/X-Role-Key:system) |
| approved/rejected 与 status.changed 同发会双重计数 | approved/rejected 仅登记幂等,聚合只看 status.changed |
| 历史任务在事件上线前创建,聚合表无数据 | 新增 POST /stats/api/v1/rebuild(admin 专用):TRUNCATE 后经 Feign 拉全量任务重算 |

## 5. 已知限制(移交后续里程碑)

1. **auth:perms Redis 缓存 TTL 10 分钟,过期后下游 @RequirePerm 一律 3001**(跨服务既有缺陷):目前靠访问 auth 的 matrix 接口回源恢复;建议 auth 侧延长 TTL 或下游缓存未命中回源——M6 前必修。
2. task.transferred 载荷不含任务状态,完成态任务转派会造成负载漂移(rebuild 兜底)。
3. rebuild 与事件并发有小窗口(truncate~重算间事件丢失);admin 工具可接受。
4. KPI 的 P0 口径按"区间创建的 P0 数"(表设计),PRD 原文"P0 且未完成"需扩表加交叉列才能严格满足;趋势图 completed 按创建日队列计,均遵循库表设计文档。
5. 逾期任务若从未收过到期提醒,会先补发一条 due.soon(spec 字面结果)。

## 4. 缺陷修复（验收/核查发现，已修并回归）

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | 导入任务 source 写死「网页」 | create 带 source 重载；导入传「Excel 导入」；API-Key 链路注入 X-Task-Source → 「OpenAPI」；防伪造 |
| 2 | 列表/详情缺 parentTaskNo | fillParentTaskNo 批量回填（列表 + 详情主任务 + subtasks） |
| 3 | 删除带评论/附件任务 FK 500 | delete 事务内级联删评论/附件记录 + 附件落盘文件 |
| 4 | JWT 无 jti，同秒重登复现被拉黑 token | JwtUtils 加 jti claim；黑名单按 auth:blacklist:{jti} |
| 5 | 限流未实现（1003 只有错误码） | 网关 RateLimitFilter：Redis 分钟桶，JWT/Key 按用户、匿名按 IP，超限 429 + code 1003 |

## 6. 遗留（上线前注意事项）

1. HTTPS：裸机/容器 nginx 当前 HTTP:8080，443 TLS 片段见安全核查清单（生产开启）。
2. 生产必须更换默认凭据：JWT_SECRET / 数据库密码 / Redis / RabbitMQ / SMTP / Nacos（见安全核查清单 §4）。
3. 压测数据（~1.05 万任务）保留在开发库，清理 SQL 见性能报告附录。
4. 附件/通知/邮件等过期清理依赖每日定时任务正常运行（M5 已交付）。
